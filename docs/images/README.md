# Diagrams

Three diagrams generated by `make_diagrams.py`. Both SVG and PNG are provided:
GitHub renders the SVG crisply at any zoom, the PNG is a fallback for contexts
that strip SVG (LinkedIn, slide decks, PDF export).

| File | Content |
|---|---|
| `architecture.svg` | Three-layer pipeline: CSV, SSIS ingestion, ODS, governance registry, analytics warehouse, BI tier |
| `star-schema.svg` | Fact table and five conformed dimensions, with member counts and the grain statement |
| `aggregation-defect.svg` | The measured 3.01x overstatement on Australia, February 2026 |

To regenerate after an edit:

    python3 make_diagrams.py

No dependencies beyond the standard library. The script writes SVG directly.
